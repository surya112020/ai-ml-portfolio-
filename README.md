# Portfolio

A modern React portfolio built with Vite and TypeScript.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

## Deployment

This project is configured to deploy to GitHub Pages using `gh-pages`.

1. Update the repository remote and branch if needed.
2. Run:

```bash
npm run deploy
```

> Replace `your-username` and `your.email@example.com` in `src/App.tsx` with your real contact details.

## Customization

- Update the hero text in `src/App.tsx`
- Replace project examples in `src/data/projects.ts`
- Add your own logo, branding, and fonts

## Notes

- The built site is generated into `dist/`
- If you want GitHub Pages to serve from a custom branch or folder, update the deployment settings in `package.json` and the repo settings
